INSPECT BEFORE EXECUTING

Your benchmark bundle

Download, unzip, review the files, then select your local kubeconfig and context using the instructions below. No cluster-wide dependencies are installed automatically.



Run with your local kubeconfig
In a terminal inside the unzipped bundle directory, set the file path and choose a context from the NAME column. Keep the same terminal open for the remaining commands.
export KUBECONFIG="/absolute/path/to/your/kubeconfig"
kubectl config get-contexts
CONTEXT="your-context-name"
bash run.sh --context "$CONTEXT" preflight
bash run.sh --context "$CONTEXT" run --confirm-context "$CONTEXT"
kubectl and Helm inherit KUBECONFIG; when unset, the standard default is ~/.kube/config. The runner has no --kubeconfig flag. Preflight is read-only; running requires explicit context confirmation. Never upload your kubeconfig to this website or share it in a bundle. See the included README.md for prerequisites, collection, resume, and cleanup.
